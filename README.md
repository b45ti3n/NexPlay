# NexPlay

Nexplay is a web game console that runs directly in your browser, without install. The screen shows the game, and players can join using their smartphones as controllers by scanning a QR code or entering the room code.

## Quickstart

### Prerequistes

| Tool    | Version | Link                                |
| ------- | ------- | ----------------------------------- |
| Git     | latest  | [git-scm.com](https://git-scm.com/) |
| Node.js | LTS     | [nodejs.org](https://nodejs.org/)   |
| pnpm    | 12.18.0 | [pnpm.io](https://pnpm.io/)         |

If pnpm is not installed, install the version used by this project from outside
the repository:

```bash
cd ~
npm install --global pnpm@12.18.0
```

### Installing

```bash
# 1. Clone the repo
git clone https://github.com/<organisation>/<depot>.git
cd nexplay

# 2. Install dependencies
pnpm install
```

### Launch

```bash
pnpm dev
```

This starts the frontend in Vite's development mode. Open
[`http://localhost:5173`](http://localhost:5173); if that port is already in
use, Vite will print the available URL in the terminal.

## Tests

```bash
# Start the test suite
pnpm test
```
